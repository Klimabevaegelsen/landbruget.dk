# Worker safety

This data was first requested from The Danish Working Environment Authority, then forwarded to and provided by [*Arbejdsmarkedets Erhvervssikring*](https://www.atp.dk/karriere/arbejdsmarkedets-erhvervssikring) at ATP.

It was downloaded on the 26th of march 2025.

## Description of the data

We have been granted access to all reported accidents resulting in more than one days absence from the place of work. The data is distributed on CVR-numbers and by year. If a company has had less than five reported accidents in a year, the exact number is not provided, but is instead denominatored as $<5$. This can be found in the sheet `Landbrug mv`.

We have also been granted access to the data, also distributed by the type of accident. This can be found in the sheet `Skadeart`.
